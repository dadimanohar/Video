First-time setup required

  1. Add the four repository secrets: GEMINI_API_KEY, YOUTUBE_CLIENT_ID, YOUTUBE_CLIENT_SECRET, YOUTUBE_REFRESH_TOKEN.
  2. Run Pipeline Smoke Test first. It validates feed access, narration, FFmpeg rendering and MP4 output without publishing.
  3. Run Daily AI News Short manually after secrets are configured. Confirm the private upload URL.
  4. Only set repository variable YOUTUBE_PRIVACY=public after Google allows public uploads for your API project.
